# 夜间模式纯黑笔迹显示修复

日期：2026-10-31。

## 行为

- 普通笔记的非 PDF 页面、无限画布，在夜间模式且实际纸色为纯黑时，将纯黑手写笔迹显示为纯白。
- 日间模式恢复原始黑色；显式设置为白色或其他非黑色的纸张保持原始笔迹颜色。
- 只匹配 RGB (0, 0, 0)，保留透明度；灰色、彩色笔迹不转换。
- PDF 页面排除在此规则外。保存数据、撤销历史与导出中的笔迹原始颜色不改写。
- 分页笔记覆盖页面缓存、高清视口、缓存增量修补、选择移动和长笔迹实时缓存；无限画布与低延迟书写层在着色器中适配，不重建文档对象。

这是本项目的设备体验修复；不宣称已取得 OneNote Android 同类行为对照证据。

## 验证

- 回归测试覆盖启用条件、精确黑色匹配、透明度、实时／完成笔迹与原始颜色保留。
- Android 像素测试覆盖 Canvas、页面缓存、长笔迹缓存与 GLES 3 着色器。
- 本地前一轮构建成功：2389 项单元测试通过，0 失败／错误／跳过；模拟器 9 项 Android 测试通过，含 3 项新增像素测试。
- 随后检查发现无限画布半透明笔迹使用独立 cover 路径，已补充同样的颜色映射与该路径的像素断言。
- 用户要求最终编译在 Linux 服务器执行，已停止继续本地构建。检查收尾日志显示，停止操作前最后一轮构建已完成（含半透明 cover 补丁和测试代码编译）；新增半透明像素断言尚未在 Android 运行。最终交付构建由用户的 Linux 服务器执行。
- 目标 MovinkPad 真机的实际书写、主题切换和性能体验待验证。
