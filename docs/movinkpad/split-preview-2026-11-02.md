# PDF 双窗格测试版

用户授权实现并本机编译供真机试用；正式发布须待用户确认。测试版必须独立安装。

## 范围与验收

- 复用 XNotes 已有 PDF 导入为本地笔记、两份文档分屏功能。两侧可组合 PDF 笔记、普通分页笔记、无限画布；用于 PDF 留白不足时在另一侧独立记录。支持同一 PDF／普通分页笔记两个独立页码／缩放视图，左右／上下切换及拖动比例。
- 同一文档共用对象和撤销记录，只有文档拥有者写入；另一视图不能另存旧副本覆盖它。原 PDF 不写入。
- 关闭任一视图保留另一位置和内容；替换文档解除共享；应用正常退出恢复双窗格位置。强杀恢复以已持久化内容为界。
- 保留现有各窗格工具栏，先支持两份同时可见的文档。多标签页管理不纳入本次测试版。
- 测试构建通过显式 `-PsplitPreview=true` 使用 `com.xnotes.movinkpad.splitpreview`，名称“XNotes 双窗格测试版”；常规 Debug／Release 的包名不变。不发布、不提交、不推送。
- 用户应导入副本，不将测试版指向正式版正在编辑的外部笔记。

## 实施与验证

沿用 Kotlin / Compose、现有 CanvasState / InteractionController；新增共享历史测试置于 app/src/test，Android 编辑器集成测试置于 app/src/androidTest。复用既有格式，不引入依赖或迁移。

1. 共享历史：先覆盖交替编辑、两侧撤销／重做、解除共享后的隔离。
2. 编辑器：共享文档、单一保存入口、视图刷新、关闭／替换生命周期和位置恢复。
3. UI：工具栏拆分入口、布局方向切换、中英资源。
4. 独立包名构建、自动化测试、模拟器安装／启动／并存检查；MovinkPad 实笔与大 PDF 性能由目标设备验证。

构建（JDK 21）：
```sh
JAVA_HOME=$(/usr/libexec/java_home -v 21) ./gradlew --no-daemon -PsplitPreview=true :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest
```

测试结果与已知限制在交付前补充。当前尚未通过目标真机验收，不宣称千页 PDF 或 Pro Pen 3 全部兼容。

## 实现说明

- 共享视图采用同一 Document、独立 CanvasState、History facade 共用时间线。保存／重命名委托 documentOwner；保留原有单文档 codec。不同笔记不共享标注。
- 关闭 owner 视图时保留另侧位置，由原拥有者继续承载剩余视图；在 owner 侧打开其他文件时，替换借用视图并交换显示位置，保留旧文档的保存队列。
- 主 session 保存共享文档一次，split-workspace.json 保存两侧位置、阅读设置、方向、比例与视觉顺序。两个不同文档各用自己的 session。
- 笔接触期间另一侧触摸不切换焦点、不重置临时工具；保留原始笔按钮位与现有取消事件处理。
- 本次发现本机 Documents 下生成 dex 缓存存在读取停滞；最终构建可通过 /private/tmp/xnotes-split-build.init.gradle 将 buildDirectory 指向 /private/tmp/xnotes-split-preview-build。此路径仅是本机构建手段，不写入工程配置。

## 使用方式

1. 首次打开测试版选“使用应用存储”，导入测试 PDF，或创建普通笔记／画布。
2. 同一 PDF／分页笔记：打开后点击工具栏固定的拆分图标。两边独立跳页、滚动、缩放；批注和撤销共用。
3. 不同文档：回到文件列表，长按选择两份笔记／画布，点击“并排打开”。PDF 应先导入成笔记。
4. 拖动中间分隔线调比例，双击回到均分；分页笔记工具栏的分屏图标切换左右／上下。关闭任一侧，另一侧全屏。
5. 测试包和正式版可并存；使用独立应用存储或复制出来的笔记，不同时编辑相同外部 .xnote/.xcanvas 文件。

验收：不同文档关闭／再开、PDF与画布工具配置往返、中心吸附逻辑单测、实际UI单一工具栏和拖动反馈；仍为独立测试包，不正式发布。

- 点击分屏直接选择本工作区文件；分页文档另提供“当前文档另一位置”。选择前不创建第二视图，取消保持现状。每侧标题行可替换／关闭，关闭一侧保留另一侧。

## 第七测试版：画布通用工具、主菜单与独立分屏文件

用户明确要求三类文档共享文本框、直尺、截图能力；左侧首页/最近旁增加分屏入口。以用户本轮明确行为为验收要求，未据此声称已逐项实测 OneNote Android 或 MovinkPad 真机。

- 无限画布新增可点按/拖出、编辑、选择变形及撤销的文本框，复用已有无边框形状文字的编码与渲染，保存重开仍可编辑。空文字草稿不留不可见对象。
- 画布直尺使用与分页编辑器相同的 Ruler 几何，支持移动、旋转、位置/角度锁定、刻度及笔迹沿边吸附；取消手势回滚位置和角度。工具不会写入笔记内容。
- 画布截图框选区域可复制为图片或分享 PNG；包括画布背景和内容，排除工具浮层；取消不修改文档。操作条限制在当前窗格内。工具加入画布默认栏及旧布局缺项迁移，跨窗格焦点可保持所选工具。
- 主菜单文件打开成功后显式退出菜单，不再依赖文档实例是否改变。按用户最终要求移除“返回之前文档”按钮，顶部/右下角均无该按钮。
- 左侧“分屏”提供“选择两个文件并排打开”“打开分屏文件”“恢复最近一次分屏”。两次文件树选择可跨目录；当前活跃分屏可从此恢复，关闭后保留最近可恢复排列。
- `.xsplit` 是独立 UTF-8 JSON 文件，format=xnotes-split、version=1，引用两侧文件 URI、文档类型、左右/上下顺序、分隔比例、焦点、页视图设置和缩放/位置。只引用原文档，不嵌入/合并内容。原文件移动、删除或权限失效后需重新选择，文件不会绕过目录授权。
- 保存打开系统文件创建器，目录由用户手动指定。默认名称按当前可见顺序为“文件一 + 文件二.xsplit”，可编辑；特殊路径字符替换，过长单个名称限制长度。两侧文件先写入成功才保存排列，不能用排列覆盖原笔记/PDF。
- 读取前验证格式、版本、有限数值及两份引用文件的可读性。先逐窗格提交文字/录音，再等待去重后的保存拥有者写完，最后同步解绑旧工作区，避免异步关闭回调关掉新文档。未确认放弃的无路径脏笔记默认拒绝替换；仅本次实际 Discard 点击记录的具体编辑器身份可跳过其保存，其他文档不受授权影响。
- 交付仍用独立测试 applicationId，versionCode 74 / 0.9.6-split-preview7。不覆盖正式版，不提交、不推送、不正式发布。

第七版验证：2408 项单元测试、37 项 Android API 32 ARM64 测试通过，0 失败。覆盖文字编码往返/撤销/重新编辑、空草稿清理、直尺吸附、截图取消与 PNG 尺寸、活动分屏替换、共享 borrower 未结束文字保存、无效引用保留当前文档、未确认/错误文档确认均不能丢弃笔记。模拟器实走主菜单打开新文件、左侧分屏选两文件、系统手选 Downloads 保存默认名、打开该 .xsplit、画布文字输入/直尺显示/截图复制；界面记录在 build/xnotes/split-preview7/。最后文字按钮映射修正仅重新构建并安装核对。包签名、ARM64 和标准安装通过；正式版 versionCode 68 / UID10153 保持不变，测试版 versionCode 74 / UID10154。交付 build/xnotes/XNotes-0.9.6-split-preview7-arm64.apk。真机压感/侧键/防误触及大型画布性能仍待目标设备验收，不以模拟器结果替代。

## 第八测试版：首页侧栏文件夹树

- 按用户要求，在展开的左侧栏“首页”下展示当前工作区根目录的文件夹；无文件夹时不占用额外栏目。最近/分屏等入口保留在树后。
- 箭头仅展开或收起子目录，文件夹名称跳转右侧浏览器；当前目录使用原侧栏的黑白选中样式。进入右侧子目录时自动展开其祖先路径。
- 子目录按需在 IO 线程读取，不递归预扫描工作区；展开状态在本次使用中保留，切换存储根目录重置。目录循环防护按 provider 文档 id 去重。
- 新建/重命名/移动/删除后的浏览器刷新通知树更新，回到首页及撤销删除也重新读取；更新时保留原已展开列表，待新结果到达后替换，避免短暂折叠跳动。
- 仅修改本地导航 UI，不修改笔记或 PDF 数据。独立测试 versionCode 75 / 0.9.6-split-preview8，不正式发布。

第八版验证：JDK 21 构建成功，2408 项单元测试通过，0 失败。模拟器实走 TreeTest → Subfolder 展开与跳转，右侧显示 Nested-test；新建 Tree-check8 后侧栏显示第三层目录，当前 Subfolder 选中状态正确，截图在 build/xnotes/split-preview8/folder-tree.png。APK 签名、ARM64 架构及标准安装通过。此次为导航 UI 修改，未重复运行此前笔输入 Android 测试；目标平板上的宽屏布局和触控手感仍待用户验收。交付 build/xnotes/XNotes-0.9.6-split-preview8-arm64.apk。

## 第九测试版：窗格内首页与应用内分屏文件

本节替代第七版的系统文件选择/保存位置交互。

- 点击编辑器分屏按钮，立即保留原文档并展开另一窗格的首页；不再显示“选择第一个/第二个文件”弹窗。主菜单“分屏 → 选择两个文档”直接显示两个首页窗格，分别点选文件进入编辑。
- 窗格首页复用 Backstage 的缩略图、搜索、排序、目录树、最近文件和新建入口，按窗格宽度适配侧栏/抽屉。替换文档也在原窗格内显示首页；选取成功前保留原文档，取消返回原文档。PDF 导入与目录授权按发起窗格路由。
- 同文件共享 owner 重定向时同步重映射首页槽位，防止新文件被另一侧首页遮住。系统返回按当前文档/首页表面处理；关闭文档后把返回处理交给剩余首页。
- 分屏保存直接原子写入应用私有 `files/splits/`，不再选择保存目录。默认名为可见顺序的“文件一 + 文件二.xsplit”，重名增加 `_N`，保留既有布局文件；内容仍为文件引用、视图和分隔布局，不合并笔记数据。
- 主菜单“分屏”列出应用保存的布局，点击恢复；保留新建两文档分屏和最近一次恢复。移除外部任意位置打开入口；加载器只接受应用内部保存目录的文件。旧外部分屏文件不删除、不自动迁移。
- 返回主菜单固定在分屏公共栏左上角，使用左箭头。尚在浏览的空窗格必须先打开文档才能保存布局。
- 明确放弃非自动保存文档的编辑后打开布局，不再错误写回该文档；未明确放弃的未保存文档保护不变。

验证：JDK 21 构建成功，2411 项 JVM 测试通过。37 项 API 32 ARM64 Android 测试通过，包括内部保存/读取、重名保留、拒绝外部布局、无效文件保留当前文档、明确放弃不写回。最后统一关闭/返回焦点处理后重新构建并在模拟器实测系统返回依次关闭文档、剩余首页、回到主菜单。实走两个首页分别打开 PDF/画布、单文档直接分屏到首页、搜索、保存后列表展示与恢复；截图及日志在外层 `build/xnotes/split-preview9/`。新增 3 项首页重定向状态测试。模拟器显示设置用于平板尺寸布局检查，不代表目标设备验收。
