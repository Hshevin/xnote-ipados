# Pro Pen 3 按钮位映射

记录日期：2026-10-30。来源：用户反馈的实测结果，针对项目目标设备 Wacom MovinkPad Pro 14 及配套 Wacom Pro Pen 3。后续项目开发复用此映射。

## 已确认的映射

| 用户编号／状态 | 原始 btn（buttonState） | 十进制 | 当前诊断工具解码名称 |
| --- | --- | --- | --- |
| 第一键 | `0x00000020` | 32 | `STYLUS_PRIMARY` |
| 第二键 | `0x00000040` | 64 | `STYLUS_SECONDARY` |
| 第三键 | `0x00000004` | 4 | `TERTIARY` |
| 不按键 | `0x00000000` | 0 | 无按钮位 |

第一、第二、第三沿用用户的编号，未另行推定笔身上的上下位置。第三键实际报告 `0x00000004`，后续适配应以该值为准。

## 复用规则

- 此表对应原始 `MotionEvent.getButtonState()` 位掩码；不将它当作 KeyEvent 键码、扫描码或应用动作。
- 判断某键是否按下使用位与，例如第一键为 `(buttonState & 0x00000020) != 0`；不按键判断为 `buttonState == 0`。组合按键的实际报告尚未验证，不据此宣称组合一定可用。
- 保留完整原始按钮位及未知位；物理键识别和后续“橡皮擦／撤销”等功能绑定分开处理。本次没有指定任何功能绑定。
- 不仅凭此掩码认定输入来自笔；适配时结合设备、source 和 toolType，避免把其他设备的相同按钮位识别为配套笔按键。

## 证据边界

用户已确认上述四种状态，随后提供了 `原始 JSON`（原始日志仅在诊断工作区本地保存，不包含在 fork）。日志元数据为 Wacom DTHA140、Android 15 / SDK 35；笔设备为 Wacom HID 422 Pen。四种按钮值均已在日志中观察到，三个非零值均出现于悬停及接触书写事件。完整统计和系统构建信息见 [真机日志分析](pen-input-analysis-2026-10-30.md)。

日志未收到 KeyEvent；第二、第三键没有独立的 BUTTON_PRESS / BUTTON_RELEASE，第一键也只有一组。因此后续应在相关 motion 事件中比较 buttonState 的变化，不能只依赖独立按钮事件。独立按钮事件与状态变化须去重。

原始日志全部使用同一场景标签；第一／二／三的物理键编号来自用户说明，日志本身不标识笔身上下位置。具体笔 SKU、系统快捷键设置和多键组合仍待补充。此次归档和分析未修改应用运行行为。
