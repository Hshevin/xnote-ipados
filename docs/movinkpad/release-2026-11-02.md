## 构建

JDK 21，保持本机原有签名密钥：

```sh
./gradlew --no-daemon -PmovinkpadPreviewSigning=true :app:testReleaseUnitTest :app:assembleRelease
```

本机通过临时 init 文件将 buildDirectory 放在 `/private/tmp/xnotes-split-preview-build/`，避免旧工作区缓存读取阻塞。最终安装包及 R8 mapping 在外层 `build/xnotes/` 留存。

## 版本 79：主菜单打开普通文件退出分屏

用户反馈从分屏返回主菜单后打开普通文件，旧的第二窗格仍显示。根因是主菜单复用了单窗格替换入口，返回菜单又只隐藏工作区。修复将主菜单普通文件打开与窗格内文件打开区分：前者先验证文件、等待两侧保存、同步解绑旧工作区，再打开单文档；后者保持只替换所在窗格。保存最近分屏供显式恢复，不使用带延迟回调的 goHome 来替换新文档。
