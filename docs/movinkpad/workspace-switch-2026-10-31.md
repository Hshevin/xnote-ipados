# 工作文件夹切换与 Pro Pen 3 设置界面

2026-10-31 用户要求：点击左上角当前工作文件夹，在多个目录和应用存储之间切换；统一 Pro Pen 3 与其它笔的快捷键设置 UI。本次明确要求本机编译。

## 行为与数据边界

- 文件浏览器顶部根目录名称带下拉标记；点击显示应用存储、当前目录和具有持久读写授权的文件夹。当前目录显示勾选；同名目录附带路径以区分。
- “添加文件夹”调用系统目录选择器。取消不改变当前目录；获取持久授权失败时显示错误。
- 切换仅改变浏览根目录，不移动、删除、复制笔记，也不释放其它目录授权。系统持久授权使目录列表在重启后仍可重建；应用存储始终存在于列表中。
- 切换前读取目录验证可访问性；失败时保留当前目录，可重新添加授权。当前目录设置采用检查结果的原子保存，保存失败也保留当前目录。
- 顶部房屋图标仍返回当前工作文件夹根目录，子目录面包屑仍按原逻辑导航。
- 已打开的笔记仍绑定原文件，不因浏览根目录变化而改写保存目的地。
- 原有“忘记文件夹”仍是显式释放权限操作，与切换不同。卸载应用仍会清除应用私有存储。
- Pro Pen 3 复用其它笔的 FieldLabel / OptionDropdown。三键并排并可随宽度换行；保留按住临时启用、按下切换与单次命令语义，物理掩码不变。
- 本次是用户指定交互；未核实 OneNote Android 是否有完全相同的多目录入口，不标记为已完成 OneNote 对齐。
